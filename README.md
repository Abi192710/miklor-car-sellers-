# Miklor Car Sellers

Mobile-first Ethiopian car dealership website built with React + Vite + TypeScript.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Included

- Mobile-first responsive layout
- Amharic / English toggle
- Search and inventory filters
- 50-vehicle-ready inventory model (18 seeded listings included; duplicate/additional listings can be added easily)
- Vehicle detail modal with WhatsApp CTA
- Favorites
- Payment calculator
- 3D-style cinematic visual treatment and lightweight motion
